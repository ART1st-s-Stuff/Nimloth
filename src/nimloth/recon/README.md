# Reconstruction models (`nimloth.recon`)

Post-hoc visual reconstruction models shared by training and evaluation code.
These packages consume frozen Nimloth state representations and do not belong
to the SFT2 or RL optimization paths.

| Subpackage | Purpose |
|------------|---------|
| `cfm/` | Conditional flow-matching image reconstruction |
| `rcdm/` | Adapter, cache, and checkpoint utilities for external RCDM |
