# 中文重写术语表

| 原概念/token | 统一中文或保留形式 |
|---|---|
| task | 任务；机器字段/路径内保留`task` |
| planning / plan phase | 规划阶段；status值`planning`原样保留 |
| implementation approval | 实施审批 |
| launch approval | 启动审批 |
| acceptance criteria | 验收标准 |
| work commit | 工作提交 |
| bookkeeping commit | 记账提交 |
| worktree | `worktree`（不译为工作区） |
| sub-agent | 子代理；标识符内保留英文 |
| context manifest | 上下文清单 |
| stop condition | 停止条件 |
| rollback / re-plan | 回滚 / 重新规划 |
| human-only | `human-only`或“仅限人类” |
| protected file/content | 受保护文件/内容 |
| experiment launch | 实验启动 |
| exact commit | 精确commit |
| remote source/worktree | 远程源码 / 远程worktree |
| curated memory | curated memory；必要时表述为“经整理的memory” |
| checkpoint | `checkpoint` |
| status / field / id | 机器值中保留英文；正文分别写“状态 / 字段 / 标识符” |

强制语义统一使用“必须”“禁止”“只有……之后”“立即停止并询问”；不得改写为“建议”“尽量”“通常”。
