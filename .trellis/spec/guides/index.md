# Cross-Layer Guides

## Applicability and authority

These guides help investigation and context selection across governance, experiment, Python, and domain layers. They do not override the topic specs or module READMEs.

## Pre-Development Checklist

- Use [investigation and uncertainty](investigation-and-uncertainty.md) to establish current evidence and stop boundaries.
- Use [known-error routing](known-error-routing.md) to select individual relevant failures for task manifests.
- Record selected specs/research/known errors and reasons in task artifacts/JSONL; do not inject the full library.
- Recheck memory evidence before relying on curated memory.

## Quality Check

- Conclusions cite current source/config/data/metadata rather than names or stale summaries.
- Assumptions, verified facts, and unresolved decisions are separated.
- Relevant known errors were checked without flooding task context.
- Verification covers the full changed cross-layer path and reports limitations.
