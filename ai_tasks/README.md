# Historical AI Tasks

`ai_tasks/` preserves pre-Trellis plans, experiment designs, progress records, and archives as historical evidence. Existing files keep their original wording and paths.

For new work:

- use `.trellis/tasks/` for requirements, design, implementation plans, checks, unresolved decisions, and execution state;
- use `.trellis/workspace/` for session journals;
- keep `AI_branch_progress.md` to concise migration-period branch milestones;
- do not create new `ai_tasks/ai_progress/` records or add live decisions to `AI_issues.md`.

Historical references inside this directory describe the authority/path conventions in effect when they were written; they do not override `AGENTS.md`, `.trellis/workflow.md`, or `.trellis/spec/`.
